# 🎲 3D Ludo Game

এটি একটি আধুনিক এবং সুন্দর 3D লুডো গেম যা HTML5, CSS3 এবং Three.js ব্যবহার করে তৈরি করা হয়েছে।

## ✨ বৈশিষ্ট্য

- 🎨 **সুন্দর 3D গ্রাফিক্স**: Three.js দ্বারা তৈরি দুর্দান্ত 3D বোর্ড এবং গুটি
- 🎯 **4 খেলোয়াড়**: লাল, হলুদ, সবুজ এবং নীল খেলোয়াড়
- 🎲 **ইন্টারেক্টিভ ডাইস**: অ্যানিমেটেড ডাইস যা ঘোরে এবং সংখ্যা দেখায়
- 🏠 **গতিশীল গুটি**: প্রতিটি খেলোয়াড়ের জন্য 4টি গুটি
- 📱 **প্রতিক্রিয়াশীল ডিজাইন**: সব ডিভাইসে নিখুঁত দেখায়
- 🌈 **আকর্ষণীয় UI**: গ্র্যাডিয়েন্ট এবং অ্যানিমেশন সহ সুন্দর ইন্টারফেস

## 🚀 ব্যবহার করার নিয়ম

1. `index.html` ফাইল খুলুন
2. **🎲 Roll Dice** বোতাম ক্লিক করুন
3. ডাইসের ফলাফল অনুযায়ী গুটি সরান
4. প্রথম ���ে খেলোয়াড় সব গুটি বাড়িতে আনবে সে জিতবে

## 📋 গেম রুলস

- প্রতিটি খেলোয়াড়ের 4টি গুটি থাকে
- 6 আসলে গুটি বোর্ডে চলতে শুরু করে
- সর্বোচ্চ 100 ঘর বোর্ডে রয়েছে
- নিজের গুটি খাওয়ালে সেটি বাড়িতে ফিরে যায়
- প্রথম সব গুটি বাড়িতে আনলে জয়

## 🛠️ প্রযুক্তি

- **HTML5**: গেম স্ট্রাকচার
- **CSS3**: সুন্দর ডিজাইন এবং অ্যানিমেশন
- **Three.js**: 3D গ্রাফিক্স এবং রেন্ডারিং
- **JavaScript**: গেম লজিক এবং ইন্টারঅ্যাকশন
